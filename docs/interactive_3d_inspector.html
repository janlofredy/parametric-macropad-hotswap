EC11 Rotary Encoder Hotswap

5 Receptacle Cavities

3 encoder pins (A, Common/GND, B at 2.50mm pitch) + 2 push switch pins. Fits standard Mill-Max 0305 receptacles or 2.54mm Dupont terminal sleeves.

Anti-Torque Chassis Slots

Dual 2.6 x 1.4mm slots at X = ±6.0mm clamp the encoder's metal side tabs, absorbing rotational torque and preventing wobble.

Push-Switch Matrix Integration

The encoder push button has an integrated 1N4148 diode bay connecting to the keyboard matrix row/column, while A/C/B route directly to GPIO.

Monolithic Gridplate Ready

Both sockets share the exact same 5.2mm depth and 19.05mm grid alignment. You can place an EC11 anywhere on the macropad grid!

Monolithic Macropad Gridplate Architecture

1. Parametric Grid Sizing

Set rows = 3, cols = 3, and standard pitch = 19.05 in macropad_grid_plate.scad to generate an instant monolithic midplate.

2. Drop-in Encoder Mapping

Define encoder_locations = [[0, 2]] to automatically convert any grid coordinate into an EC11 hotswap socket with anti-torque slots.

3. Continuous Matrix Trenches

Continuous horizontal Row channels and vertical Column channels run unbroken across the entire plate for fast bus-wire handwiring.
